# Ortopedi Simülasyon PWA

iPhone'da Safari üzerinden açılıp Ana Ekran'a eklenebilen, çevrimdışı önbellek destekli ortopedi soru-cevap ve simülasyon uygulaması.

## Yayınlama
GitHub Pages ayarlarında **Deploy from a branch** seçin, branch olarak **main**, klasör olarak **/(root)** seçip kaydedin.

## iPhone'a yükleme
1. Yayınlanan GitHub Pages adresini Safari'de açın.
2. Paylaş düğmesine dokunun.
3. **Ana Ekrana Ekle** seçeneğini seçin.
4. Ekle'ye dokunun.

Uygulama ilk çevrimiçi açılışından sonra temel dosyalarını önbelleğe alır. İlk yükleme için internet bağlantısı gerekir.
